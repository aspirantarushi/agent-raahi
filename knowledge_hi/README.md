# Hindi versions of knowledge entries (हिंदी अनुवाद)

Each entry gives its English heading, a Hindi translation of the text, and the Source, Link and
Checked lines copied exactly from the English file in knowledge/. Section numbers, dates and
amounts must match the English exactly (a test checks this). Each entry ends with
"Hindi translation checked: no" until a Hindi speaker who knows the law has checked it; then
change it to "yes". If an entry is missing here, the app shows the English one.
