# Practice Clinic: Supervisor

Sign in on the **Supervisor** page with the supervisor password (from the coordinator), then type
**Supervisor** as your name, exactly as written (never your own name). You must not be one of the five
volunteers: no one can approve their own work. Every case is made up.

Cases arrive as the volunteers send them: they show under **Waiting for review**. For each one, read the
summary, the drafts and any research points, then do what this sheet says. Use the case's code (the
volunteer can read it out) to find it in the table of all cases.

**Do not write anything in the Impact log.** These are practice cases.

## How

- **Approve:** in the case's review box, under **Your decision**, choose **Approve**, then press
  **Approve and save**.
- **Send back:** choose **Reject with a reason**, type the reason above, then press **Send back**.
- **Close** (only after approving): in the table of all cases, type the code in the search box, click the
  case's row, and under **Close this case** choose the reason **Referred elsewhere**, type the note
  (`cyber police` or `Lok Adalat`) in **Short note (no names)**, then press **Close case**.
- Each review box has a closed card **What the agent did**: open it to see what the agent did on the case
  and when.
